# 🍽️ Zomato Restaurant Ratings Analysis (EDA)

Exploratory Data Analysis of restaurant ratings to identify how factors such as online ordering, table booking, votes, pricing, and restaurant type influence customer ratings.

</div>

## 📌 Project Overview

* Performed Exploratory Data Analysis (EDA) on a Zomato restaurant dataset.
* Investigated factors affecting restaurant ratings.
* Analyzed customer engagement, pricing, and service-related features.
* Extracted actionable insights from restaurant performance patterns.

---

## 📂 Dataset Description

The dataset contains restaurant-level information including:

* Restaurant Name
* Online Order Availability
* Table Booking Availability
* Rating
* Number of Votes
* Approximate Cost for Two People
* Restaurant Type

---

## 🧹 Data Cleaning

* Removed `/5` from rating values and converted ratings to numeric format.
* Handled inconsistent data formats.
* Renamed columns for better readability.
* Verified data types before analysis.

---

## 📊 Univariate Analysis

* Distribution of restaurant ratings.
* Distribution of votes received by restaurants.
* Frequency of restaurant categories.
* Online ordering and table booking availability.

---

## 📈 Bivariate & Multivariate Analysis

* Online Order vs Rating
* Table Booking vs Rating
* Votes vs Rating
* Cost for Two vs Rating
* Restaurant Type vs Rating

---

## 🔍 Key Insights

1. Restaurants offering **online ordering** tend to receive slightly higher ratings.
2. Restaurants with **table booking facilities** generally achieve better ratings.
3. Restaurants with **more customer votes** tend to maintain higher ratings.
4. **Pricing and restaurant type** show relatively weak influence on ratings.

## ✅ Conclusion
